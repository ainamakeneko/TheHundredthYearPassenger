# 私立探偵ヴァン・レイ ― 百年目の乗客

百三年ぶりに帰還した宇宙船《エルピス》をめぐるハードボイルド探偵ADVです。

このローカル版は、元の9章に4つの調査区間と証拠照合を追加した拡張捜査版です。元の9章版も `original/index.html` に残しています。操作・変更点は [EXPANSION.md](EXPANSION.md)、検証結果は [TEST-REPORT.md](TEST-REPORT.md) を参照してください。

事件に必要な証拠だけでなく、時計、街灯、濡れた床、コーヒー販売機などを眺めながら、環状都市ノクターンで探偵として時間を過ごします。選んだ対象や会話人物は画面内に画像で表示され、章ごとの幕間を経てエンディングまで進みます。

## 遊び方

1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. スマートフォンでは横画面を推奨します。
4. BGMは画面上部の `JAZZ OFF` を押すと再生されます。

## 操作

- 見る：人物、物、風景を観察する
- 話す：その場にいる人物と話す
- 考える：集めた情報について思考する
- 移動する：別の場所へ移る
